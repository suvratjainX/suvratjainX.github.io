## FAQ

#### 1.Who all can use this?

Anyone who wants to remake, redesign, improve, or learn from this project is free to do so. However, the original creator (Suvrat Jain) must be credited for the base project.

#### 2.Can I modify the source code?

Yes. You are welcome to modify the source code to suit your needs, add features, fix bugs, or improve the design.

#### 3.Can I redistribute my modified version?

Yes, provided that proper credit is given to the original project and creator.

#### 4.Is this project open source?

Yes. The source code is publicly available for educational and community use.

#### 5.How do I report bugs or suggest features?

You can open an issue on the GitHub repository or contact the project owner with details about the bug or suggestion.

#### 6.Will more content be added in the future?

Yes. New granths, bhajans, features, and improvements may be added over time.

#### 7.What technologies were used to build this project?

This project is built using Next.js, React, TypeScript, HTML5, CSS3, and Tailwind CSS.

#### 8.Who maintains this project?

The project is maintained by Suvrat Jain.

#### 9.Is an internet connection required?

Only for accessing the hosted website. Once the files are downloaded, static content can be viewed locally.

#### 10.How can I support this project?

You can contribute code, report issues, suggest improvements, or share the project with others interested in Jain literature.
